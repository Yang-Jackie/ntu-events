# API client

This private workspace package exposes the typed Fetch client for the Django
API.

- `openapi.json` is generated by `drf-spectacular`.
- `src/generated/schema.d.ts` is generated by `openapi-typescript`.
- Generated artifacts are committed and must not be edited manually.
- `src/create-client.ts` accepts runtime configuration from its caller and does
  not read Next.js environment variables.

Run `pnpm api:generate` from the repository root after changing the API.
